# Nura builds for Poco F3 (alioth)
Formerly known as postmarketOS. Learn more [here](https://nura.eco/blog/2026/09/27/nura-rename).

This repository preserves working Nura builds for the Poco F3 (codename **alioth**).

## Disclaimer
- All builds were originally produced by other developers
- This repository does not guarantee that any build works correctly or safely
- Builds may contain bugs, incomplete features, or experimental changes
- You are fully responsible for anything that happens to your device when using these builds
- Everything is provided as is

## Want a weekly build?
- Grab the newest one from [here](https://github.com/Sucharek233/alioth-nightly-builds/actions)!
- Don't have a GitHub account? Download from [here](https://nightly.link/Sucharek233/alioth-nightly-builds/workflows/build/main/xiaomi-alioth)
- The workflow run in the repo releases builds **every Friday**
